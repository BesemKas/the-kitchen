# Label reader (third-party files)

These files are copied unchanged so the label reader runs on the phone from this server, with nothing loaded from elsewhere.

- `tesseract.min.js`, `worker.min.js`: tesseract.js 5.1.1, Apache License 2.0, https://github.com/naptha/tesseract.js
- `core/*.wasm.js`: tesseract.js-core 5.1.1 (Tesseract OCR compiled to WebAssembly), Apache License 2.0, https://github.com/naptha/tesseract.js-core
- `lang/eng.traineddata`: English model (4.0.0_best_int) from tessdata via @tesseract.js-data/eng, Apache License 2.0, https://github.com/tesseract-ocr/tessdata
